# 世界时钟

通过当前连接中的 `get_current_time` 查询用户关心的各个 IANA 时区，例如上海 `Asia/Shanghai`、伦敦 `Europe/London`、纽约 `America/New_York`。同名城市或 CST 等缩写有歧义时先确认地点，不把服务器默认时区当作用户时区。

报告城市、完整当地日期、时间及 UTC 偏移；查询不是原子快照，不把几秒差异解释为时差。判断是否适合联系时，优先用用户给定作息，否则明确假设周一至周五 09:00–18:00，不把这个假设当作节假日或实际在线状态。

没有工具或调用失败时说明无法取得实时数据，不编造“现在”。此 Skill 只读时间，不发消息、不设置提醒。
