# 截止时间换算

先确认原始截止日期、钟点、来源时区及目标地点。“月底”“今晚”“EST/CST”等模糊表达须澄清，不能自行确定有业务后果的截止时刻。

发现当前连接的 `get_current_time` 和 `convert_time` 工具。相对日期按用户明确的来源时区解释，当前时间由工具查询。

检查 `convert_time` 的实际参数和返回日期。若它只接受 HH:MM、按来源地今天换算，只处理与该日期相符的截止时刻。其他日期需要客户端已有的带 IANA 时区数据库的计算能力；不可把今天的 UTC 偏移套用到未来日期。遇到夏令时跳过或重复的当地钟点，要求明确 UTC 偏移或绝对时间，不静默选择。

输出原始截止时刻及每个目标地完整日期、钟点、IANA 时区、UTC 偏移；特别标记前一天/后一天。只有取得当前时间后才计算剩余时长，已经截止则明确说明。换算不改变截止规则，不创建提醒、不提交业务操作。
