## 信息与交互决策

- 先选择固定版本，再选择本地/远程及端点绑定，文件查看器和下载动作共用同一选择。新请求隔离旧异步结果，不用 local 内容冒充缺失 remote。
- local-only 显示尚未适配及“创建新版本”，保留 ZIP/CLI。remote-only 不显示虚假的本地安装指引。共享文件显示一致内容；不同字节才切换变体。
- 远程面板检查实际发布、来源和开关，提供端点与认证头占位符，不包含真实 Key。“最近检查可连接”不是永久授权或 Host 自动激活承诺。
- 生成中显示持续反馈，来源锁防止重复提交，失败可重试；未变更不误报新草稿。新内容仍须审核发布。
- 桌面文件树/正文分栏，窄屏使用文件下拉与纵向动作；Markdown 的 YAML 头作为代码展示，正文渲染。源码、复制和下载保持原文。二进制明确不可在线预览，不伪造文本。
- 侧栏使用原生 InkWell 与按钮/选择语义、可见键盘焦点、至少 44px 目标，减少动画偏好下取消装饰过渡。状态不只依赖颜色，导航、模式选择和源码切换有键盘测试。

本次使用 UI/UX 规范的加载/失败/响应式/焦点建议；不采纳搜索结果中营销 Hero、销售 CTA 或额外字体下载建议，它们不适合现有管理控制台。业务请求在 Riverpod/API 层，Widget 只管理展示与用户意图。
