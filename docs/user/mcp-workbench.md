# MCP 测试台

测试台的发现、读取与应用请求使用独立的 45 秒浏览器等待预算，容纳后端 25/30 秒期限及网络返回；其他管理请求保持原超时。浏览器等待首个响应期间不会在 10 秒时误报连接失败。交互式运行仍查询原调用状态，失败不自动重发；真正超时也不保证远端副作用撤销。

在 MCP 服务中点击「测试」，使用当前登录身份验证 Agent 通过这个地址实际可以使用的能力。测试台不直接显示后台管理索引，也不自动使用管理员凭证。

## 五个入口

- **工具**：填写参数后执行真实调用；可能修改数据，超时不代表操作已撤销，不自动重试。
- **资源**：选择资源后读取；资源模板填写参数后生成 URI。Markdown 支持阅读，HTML 和脚本只显示内容，二进制保留原始响应，不执行文件。
- **提示模板**：填写参数后获取按角色组织的消息，不调用模型。
- **Skills**：自动识别访问方式，按需读取文件，提供内容校验和源码查看。不会在服务器执行 Skill 脚本。
- **应用**：从当前端点的工具关联发现应用。默认只读取隔离界面；需要动态结果时填写入口 JSON 参数，确认「调用入口并预览」。应用内真实工具调用需要开启真实测试并逐次确认。模拟预览不访问外部网络；外部域名授权与工具调用授权分别处理。

列表支持分页、搜索、刷新。未支持、没有内容和读取失败分别展示。切换身份或重新连接会清理旧结果和应用预览；窄屏可从详情返回列表。测试台不会将任意 HTML 资源自动当成应用。

## 诊断与限制

「执行记录」只保留本会话最近 100 项操作的状态和耗时，不保存参数或凭证。「接入 Agent」提供当前站点地址；通过反向代理访问时请使用用户实际能访问的站点。认证信息单独配置，不嵌入地址。

浏览和旧同步接口最长 25 秒，最多 8 项并发；新工具调用独立提供最多 8 项并发、300 秒总期限，每会话只允许一项活动调用并保留最近 20 项结果。结果上限 16 MiB，文本阅读上限 256 KiB。二进制可在原始响应检查。接口失败不自动重放真实工具调用。

## 长任务与补充信息

工具执行后可以查询状态、查看结果或请求取消。端点声明支持远程任务时，可以勾选「使用远程长任务」，但工具本身也必须支持任务执行；失败不会自动改为普通调用。这里显示的是当前测试会话的调用，不是平台全局任务列表。切换身份、关闭或重建会话后，旧结果不可复用。

服务要求中途补充信息时，界面显示字段表单，可提交、拒绝或取消本轮询问。只填写非敏感信息，不填写密码、令牌或其他秘密。回答会根据服务请求的类型与必填字段校验；不跟随外部 Schema 引用。

网页交互会单独显示目标网站和完整地址。核对目的后可点击「打开网页」，在目标网页完成操作后再点击「我已完成，继续」，也可以拒绝或取消。打开网页本身不会自动确认；mcpcat 不替你访问链接，也不接收网页中的密码或令牌。HTTP 地址会提示未加密。该操作与连接 MCP 服务本身的 OAuth 授权不同。

远程任务取消是合作式请求，界面会等待远端终态；普通调用取消只停止等待，不能保证远端业务撤销。超时或状态查询失败后，应先核实业务结果，不重复点击执行。

HTTP、STDIO 来源的远程任务由来源 MCP 执行，mcpcat 代理提交、查询、补充回答及取消，并将任务绑定到提交身份。其他身份不能操作该任务，密钥撤销后不可继续访问；来源重启会使旧网关任务 ID 失效，不代表上游业务已撤销。任务映射只在当前运行实例保留，最多保留一小时，每个来源最多 128 项（含提交中的请求）。

STDIO 任务会保留创建任务时的原连接，每个来源最多同时持有 8 个任务连接，创建中的连接也计数。任务完成后连接仍按保留期限存活，以便再次查询结果；过期、撤权、来源停服或重启会关闭连接及对应子进程，不自动启动新进程重放任务。支持任务中的补充回答、拒绝和取消输入，也可以请求取消等待输入或执行中的任务；取消是否成功以远端终态为准。旧 SSE 来源不声明现代 Tasks。

应用真实调用只允许当前端点实际列出的工具；无法发现的 UI 专用工具不会自动放行。应用支持程度取决于其资源策略、回调和客户端能力，界面显示不等于所有交互均已通过验证。

测试台通过只证明当前身份、端点和此测试客户端的链路可用，不保证任意第三方 Agent 自动加载 Skills 或支持应用。Skills 管理中心的上传、版本、ZIP 和 CLI 安装保持不变。

## 参数补全

提示模板与资源模板的参数输入框提供「获取候选值」按钮。仅在主动点击时向 MCP 请求候选，携带其他已填参数作为上下文；选择候选不会自动读取资源或调用工具。修改任一参数会清除旧候选。服务未提供补全时仍可手动填写。

## 连接与授权诊断

顶部「连接与授权诊断」在连接失败时也可打开。默认只读取已保存状态；点击「实时探测上游」才会检查已配置的 HTTP/SSE 来源及其授权元数据，不调用工具、不自动登录、不刷新令牌、不改写配置。诊断分别显示当前 mcpcat 身份和上游授权情况；网络、超时、协议错误不会显示为无需认证。

显式配置机器认证的来源会单独标注。打开面板不申请令牌；点击探测会用已配置机器凭证申请短期令牌并建立 MCP 连接，不持久化令牌、不修改来源配置、不调用工具。失败时检查服务端凭证、授权范围及网络，无需浏览器登录。机器凭证不以旧交互式 token 的有效期判断，界面不展示密钥、私钥引用或令牌正文。

上游要求授权时，到对应 MCP 服务的授权设置处理。已存令牌通过本地有效性检查不保证上游仍接受它；实时探测成功也不代表所有工具操作均已获授权。聚合端点需要分别检查各个来源，不会一次探测所有服务。STDIO/OpenAPI 来源不套用此 HTTP OAuth 探测，也不会为诊断额外启动进程。

## 事件与订阅

连接成功后，从顶部「事件与订阅」查看实际收到的协议事件。可选择工具、资源、提示列表变化，以及每行一个资源 URI，然后点击「开始订阅」。实际范围以服务端确认的过滤器为准；不支持或中断会显示失败，不自动重连。修改范围前先停止订阅。

工具进度是实际调用的通知，不是远程任务轮询的别名。面板最多保留最近 200 条事件，缓冲区丢弃旧事件时会提示重新读取关心的内容；不记录日志正文或凭证。关闭面板不停止监听，停止订阅或关闭测试会话才释放连接。身份变化会清空旧展示。当前网关来源事件的完整兼容验证尚在进行，不能将面板可用等同于所有来源都提供通知。

独立 Skills 与 Apps 端点已接入新版协议订阅：发布或撤销当前身份可见的内容会通知列表变化，草稿和无权访问的内容不会通知。Apps 的工具与资源列表也会随绑定来源的公开权限变化更新。收到列表变化后重新读取目录；通知不携带文件正文，也不会执行 Skill 脚本或 App 业务工具。已有连接的 Key 被撤销时订阅会结束，即使端点允许匿名访问也不会自动降级。

旧协议客户端首次读取平台目录后，可接收列表变化通知；资源更新仍需显式订阅对应 URI。重复订阅会复用同一会话监听，每会话最多 32 个资源 URI，每端点最多 32 个旧会话监听。断线、撤权和停服均清理监听，失败不自动重连。来源附加与聚合端点的完整通知覆盖仍在补齐中。

重启 MCP 来源会结束原有订阅；重新连接后可再次订阅，新实例保留通知能力。带 Key 的来源订阅在该 Key 失效后结束，不自动切换成匿名连接；原本未带 Key 的公开来源订阅仍可正常使用。

普通代理来源附带的 Skills 可与上游通知共用当前地址。发布可见 Skill 或其依赖工具失效时，会通知资源目录变化；平台 Skill URI 不会作为订阅参数发送给上游。来源明确不支持通知时，平台自身的通知仍可提供，但界面不会将上游工具或资源更新标记为已订阅。

OpenAPI 来源附带的 Skills 也支持发布/撤销通知，新旧客户端均可使用；停止或重启来源会结束旧订阅。此功能不代表能监听任意 REST 接口的数据变化。

Catalog 聚合入口支持平台管理内容的目录通知：附带 Skill 和托管 App 发布/撤销后，只有实际能看到内容的身份才收到相应资源或工具列表变化。关闭 Catalog 或撤销 Key 会结束订阅。

聚合上游的应用目录和资源更新已接入实时监听，资源更新使用 Catalog 返回的映射 URI，不能用来源原始 URI 替代。来源移出聚合时释放其监听，重新纳入后重建；订阅不执行业务工具。每条聚合订阅最多监听 32 个来源，缓冲最多 200 条事件，超过限额或来源流异常会结束订阅，不会静默丢弃后继续宣称完整。当前真实测试覆盖新版 HTTP 上游与新旧下游；其他传输、来源替换和跨进程链路仍需完整验收。

## 模拟 Sampling 响应

任务调用也可等待手工 Sampling 回答，仍需先显式开启模拟能力。支持工具型响应和同轮目录等其他问题；测试台只返回数据，不自动执行模型返回的工具。部分来源执行引擎只接受文本结果，如果上游拒绝回答，测试台报告失败，不改写响应或自动重放原调用。

「客户端能力测试」中的「模拟 Sampling 响应」默认关闭。开启并重新连接后，工具调用、资源/资源模板读取、提示模板读取若请求 Sampling，测试台展示请求上下文，等待你填写符合 MCP 结果格式的 JSON，或者拒绝/取消。这些读取同样显示运行状态并支持停止等待，保留资源 `contents` 与提示 `messages` 的原始结构。不会调用真实模型，也不会执行响应中的工具指令；提交的结果会交给所测试的 MCP 服务，请自行评估该服务后续可能执行的操作。

请求正文与手工响应各限制 64 KiB。不要把请求正文当成操作授权，不要填写密码、令牌或不愿向服务披露的资料。已验收新旧协议普通调用、现代任务及浏览器手工文本响应；具体来源能接受的结果仍以实际协议响应为准。

## 客户端目录声明（Roots）

测试台顶部「客户端能力测试」可声明模拟目录：开启「声明 Roots 能力」，每行填写一个 `file:///` URI，再点击「应用并重新连接」。该操作会关闭旧测试会话，清除旧结果与订阅。取消不修改配置；关闭声明后重新连接则不再提供此能力。

创建测试会话时，可选传入 `client_options.roots`，例如 `{"roots":[{"uri":"file:///example/workspace","name":"测试工作区"}]}`。省略时不声明 Roots 能力；传入空数组表示支持该能力但没有目录。最多 32 项，只接受 `file:` URI，名称最多 256 字符。

这是手工声明的模拟客户端目录，不会扫描或读取 mcpcat 服务器磁盘，也不授予上游文件访问权限；不要填写不愿向所测服务披露的路径。配置只保留在当前页面，切换身份或服务后清除。该入口需更新后的前端构建；旧部署不会自动出现。
