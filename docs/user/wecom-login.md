# 企业微信登录

mcpcat 支持单企业自建应用的 Web 登录。成员授权后自动加入团队，沿用 API Key 和只读/读写权限；管理员可在同一团队页面管理飞书与企业微信成员。

## 准备部署地址

使用企业自有域名和 HTTPS 访问 mcpcat，例如 `https://mcpcat.example.com/ui/`。在企业微信后台配置授权回调域及相关可信域名时，按平台要求填写域名，不带协议头，不支持 IP 和短链域名。

mcpcat 中填写的是完整回调地址：

```text
https://mcpcat.example.com/api/auth/wecom/callback
```

回调地址不含查询参数或 `#`。登录前后必须使用同一域名、协议和端口，不能从 localhost 发起登录后回到另一个域名。

回调由发起登录的浏览器访问。使用内网 DNS 或 VPN 部署时，浏览器需能解析并访问上述域名，且域名必须通过企业微信后台要求的配置校验。后台如要求域名校验文件，需按其要求提供；不能因为服务在内网就省略域名校验。

后端需能访问 `qyapi.weixin.qq.com:443`。代码允许 localhost 使用 HTTP 仅用于开发，不代表企业微信平台接受 localhost 登录。

## 配置自建应用

1. 在企业微信管理后台创建企业自建应用，取得 CorpID、AgentID 和应用 Secret。
2. 配置应用可见范围、企业微信授权登录的 Web 回调域，以及后台要求的可信域名和企业可信出口 IP。
3. 使用管理员 API Key 进入 mcpcat，打开“团队成员管理 → 企业微信设置”。
4. 填写企业应用信息与完整授权回调地址，选择新成员默认权限，然后启用并保存。默认权限为只读。
5. 从上述 HTTPS 域名打开登录页，点击“使用企业微信登录”完成授权。

应用 Secret 加密保存，不会在配置响应中回显。编辑设置时，Secret 留空表示保留原值。

## 成员与权限

- 以企业 ID + UserID 唯一识别成员；首次登录自动注册，再次登录保留原权限、启用状态和过期时间。
- 无法读取姓名或头像时，以 UserID 展示成员，不要求读取手机号或邮箱。
- 飞书和企微账号各自独立，不会按姓名自动合并。
- 修改成员权限或禁用成员，对后续请求生效。需要阻止访问时使用禁用；删除账号后，再次授权登录可以重新注册。
- 当前没有组织通讯录同步或离职事件订阅，已签发的本地访问凭证需要管理员在 mcpcat 中管理。

## 升级注意事项

更新镜像时保留 `/app/.mcpcat` 数据卷和现有环境变量，特别是 `MCPCAT_SECRET_KEY`。启动会按现有机制备份并升级数据库，原 API Key、飞书账号和 MCP 配置保留。首次升级前仍应保留完整的数据卷备份；回滚旧镜像时，需要同时恢复与旧镜像匹配的升级前数据快照。

企业微信登录默认关闭，升级后需要管理员配置应用并主动启用。公网镜像是否包含此能力，以对应标签的发布内容为准。
