# 在测试页面检查远程 Skills

进入 MCP 服务的「测试」页面，切换到 **Skills** 页签。页面使用你当前的 Key 连接真实 MCP 端点，不从 Skills 管理索引拼出测试结果。

1. 平台自动识别访问方式；有分页时点击「下一页」。发现不会预读正文，不需要选择底层实现。
2. 点击 Skill 后按需读取文件。Markdown 支持预览/源码切换；脚本只作为文本展示，图片不会自动联网加载。
3. 已知 URI 即使没有出现在列表中，也可粘贴后点击「按 URI 查询 / 刷新元数据」，测试 `skills/get`。
4. 静态文件按持有清单核验原始字节数与 SHA256，入口同时核验全部 frontmatter。不一致会阻止预览，需显式刷新元数据；不会悄悄接受新版本。
5. 动态资源明确标记没有静态摘要。仅当服务声明 `directoryRead` 时显示目录测试；目录结果是实时观察，不扩充静态清单。

如果服务未声明标准扩展，但提供兼容 Skill 资源，平台自动通过资源发现和文件清单读取。该方式不代表标准静态完整性通过；标准扩展已声明却调用失败时会明确报错，不偷偷切换。访问方式和协议信息放在「高级诊断」。

会话和每个 Skill 的身份绑定当前用户、端点和 URI，同名 Skill 不会合并。凭证撤销或更换后须重新建立会话。单次协议操作上限 25 秒，静态清单最多 512 文件、16 MiB；文本预览上限 256 KiB，二进制只显示元信息。

测试成功仅证明发现/读取链路可用，不证明 Agent 已自动激活 Skill，不授予工具额外权限，更不会在 mcpcat 执行上传脚本。ZIP 下载、CLI 安装及已有内容不受影响。

其他能力见 [MCP 测试台](mcp-workbench.md)。
