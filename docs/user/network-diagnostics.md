# 网页命令执行与网络诊断

使用管理员（WRITE）API Key 登录，打开左侧 **命令执行**。
默认选择 **自由命令**，直接输入命令或多行脚本，点击 **执行**。
例如：

```bash
pwd && ls -la
ping -c 4 example.com
printf 'hello\nworld\n' | grep world
```

命令在 **MCPCat 所在服务器或容器** 执行，权限与 MCPCat 应用进程相同，
可以修改该系统用户有权限访问的文件与服务。结果反映服务端环境，不是浏览器或用户电脑的网络。
Linux/macOS 使用 `/bin/sh -c`，Windows 使用 `cmd.exe /d /s /c`，语法随服务端系统变化。
支持管道、重定向、引号和多行脚本；需要 Bash 语法时可显式调用已安装的 `bash`。

每次执行都是独立的非交互 Shell，从应用工作目录开始；需要其他目录可输入
`cd /path/to/project && command`。目录和临时变量不会保留到下次执行，文件修改会保留。
不提供终端输入，要求密码输入或交互确认的命令应改用非交互参数。

输出合并标准输出与标准错误，按完整行实时显示，可停止、选中文本或复制结果。
退出页面、切换身份或断开连接会取消执行。结果展示退出码，非零退出码为失败。
超时可选 5、15、30、60 秒，每个应用 worker 最多同时运行两次命令，
原始输出上限为 64 KiB，超出后停止执行。普通子进程随所属进程组/树回收；
不要将此入口作为持久后台服务管理器，自行脱离进程组的后台程序不保证被回收。

已知配置凭证和常见 token 格式会脱敏，过长单行整体省略。
命令不默认继承应用秘密环境变量，但这不是隔离沙箱：管理员仍可执行系统用户有权限的命令。
后台诊断日志记录执行开始与结束状态，不保存脚本文本或完整输出。
复制或分享输出前应检查是否含业务信息。

## 网络诊断快捷项

也可以选择以下快捷项，免于记忆参数。从 **诊断日志 → 网络诊断** 可以直接进入此页面。

| 命令 | 输入示例 | 用途 |
| --- | --- | --- |
| Ping | `127.0.0.1` 或 `example.com` | 执行系统 ping，共 4 次 |
| DNS 解析 | `example.com` | 查看服务端解析得到的 IP |
| TCP 端口连接 | `example.com`，端口 `443` | 检查实际服务端口是否能建立连接 |
| HTTP 响应头 | `https://example.com` | HEAD 请求，检查 TLS 与 HTTP 状态；不跟随重定向 |

Ping 无响应可能是 ICMP 被禁用，可继续用 TCP 检查服务端口。
新版官方镜像包含 `iputils-ping`；自建环境缺少 `ping` 时需维护者安装。
