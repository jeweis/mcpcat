# 网页命令执行与网络诊断

使用管理员（WRITE）API Key 登录，打开左侧 **命令执行**，选择命令、填写目标，点击 **执行**。
也可以从 **诊断日志 → 网络诊断** 进入。

命令在 **MCPCat 所在服务器或容器** 执行。结果反映服务端网络，不是浏览器或用户电脑的网络。
输出实时显示，可停止、选中文本或复制结果。退出页面、切换身份、断开连接会取消执行。

| 命令 | 输入示例 | 用途 |
| --- | --- | --- |
| Ping | `127.0.0.1` 或 `example.com` | 执行系统 ping，共 4 次 |
| DNS 解析 | `example.com` | 查看服务端解析得到的 IP |
| TCP 端口连接 | `example.com`，端口 `443` | 检查实际服务端口是否能建立连接 |
| HTTP 响应头 | `https://example.com` | HEAD 请求，检查 TLS 与 HTTP 状态；不跟随重定向 |

执行超时可选 5、15、30、60 秒。正常完成显示退出码；非零退出码、超时、环境缺少工具等都会显示原因。
每个应用 worker 最多同时运行两次诊断，原始输出上限为 64 KiB，超出后停止执行。
过长单行会省略，避免拆开凭证后绕过脱敏。已知配置凭证和常见 token 格式会被脱敏；
复制或分享输出前仍应检查是否包含业务信息。

Ping 无响应不一定表示服务不可达：目标可能禁用 ICMP，容器也可能没有发送 ICMP 的权限。
可继续使用 TCP 检查实际服务端口。新版官方镜像包含 `iputils-ping`；
自建环境缺少 `ping` 时需要维护者安装，页面会提示原因。Windows 使用系统 ping 的参数。

此入口提供固定网络诊断命令，不运行任意 Shell 文本，不支持管道、重定向或命令组合，
也不继承应用的 API Key、数据库密码等环境变量。后台诊断日志记录执行开始与结束状态，
不保存完整命令输出、URL 查询参数或用户输入。输出仅通过当前认证请求返回。
