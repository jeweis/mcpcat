# 使用 CodeMode 编排 MCP 工具

平台固定提供 CodeMode，Agent 连接独立的 `/mcp/code-mode`，像调用普通 MCP 工具一样使用 `search`、`get_schema`、`execute`。这是 FastMCP 的实验性编排接口，不是新的 MCP 官方方法，也不是 Skill 脚本运行器。当前为升级代码能力，尚未对外发布。

## 接入与安全设置

无需启用开关。在全局设置的 CodeMode 面板查看实际地址、状态并限定来源和工具，也可用 WRITE 身份访问 `GET/PUT /api/admin/settings/code-mode`。配置示例：

```json
{
  "path_name": "code-mode",
  "allowed_services": ["weather"],
  "allowed_tools": ["weather__forecast"]
}
```

服务名、工具名必须替换为当前 Catalog 的真实公开名称；不是通配符。`null` 表示不进一步缩小原 Catalog 范围，`[]` 明确禁止全部。现有 OAuth 来源仍按原纳入规则排除；App 打开、UI-only 回调及网关递归元工具不进入编排目录。配置不扩大调用者原权限。

固定提供且必须认证，不能改为匿名执行。更换路径后按状态提示重启；`ready=true` 才表示实际入口就绪，保存成功不等于已经挂载。升级时若旧服务占用默认地址，系统自动持久化避让到 `mcpcat-code-mode`（必要时加数字后缀），原服务地址不变；以设置面板的实际路径为准。手动修改路径不能与其他入口冲突。正常部署仍保持单实例。旧 `enabled` 输入兼容忽略，不再控制功能。

## Agent 如何调用

在客户端安全配置中设置实例地址和 READ Key，认证头默认 `Mcpcat-Key`；不要把真实 Key 放进 URL、代码、Skill 或日志。客户端只需支持普通 MCP 工具，不要求官方 Skills 扩展或专有 CodeMode 协议。

1. `search` 的参数例如 `{"query":"天气预报"}`，查询可用工具。
2. `get_schema` 的参数例如 `{"tools":["weather__forecast"]}`，获取实时参数 Schema。
3. 根据真实 Schema 调用 `execute`，参数为 `{"code":"..."}`。代码通过 `await call_tool("公开工具名", {...})` 调用已授权工具，最后 `return` 数据。

例如仅演示无副作用计算的代码可以是 `return 1 + 2`。业务参数必须来自当前工具 Schema，不能照抄其他实例的名称。工具结果是 MCP 调用结果；不要假定所有工具都返回同一 JSON 形状。写入、发送消息、费用等操作仍需用户明确意图和工具自身授权，不因一次 execute 包含多个调用而被自动批准。

## 代码在哪运行

编排代码在 mcpcat 的 Monty 沙箱中计算；被调用的业务工具在其配置的 MCP 服务环境执行。客户端不在本地执行这段编排。沙箱不提供宿主磁盘、shell、任意网络、凭证或 Skill 制品读取能力。

上传 Skill 的 Python/JS/shell 仍只作为文件保存和分发，由客户取得后在本地 Agent 环境执行。CodeMode 不会根据文件路径导入/运行它们；原 local Skill 继续使用 mcporter，原 remote 模板继续绑定服务或 Catalog，不自动改接 CodeMode。

## 限额、失败和取消

默认每次沙箱计算 30 秒、内存 100,000,000 字节、代码 65,536 字节、50 次工具尝试；工具并发 4、同一身份 execute 并发 2；单工具 30 秒、总请求 120 秒。管理员可在有限范围内调整，不能设为无限制。失败和重试尝试也计数，等待工具仍受单工具及总 deadline 约束。

超限、撤权、来源停用或错误会停止后续调度，返回安全诊断；已成功的写操作不会自动回滚，不自动重试整段代码。取消可传播到配合取消的上游，但不能保证撤销已完成或不配合取消的业务动作。遇到结果不明时先核对外部状态，再决定是否重试。不可确认结束的本地调用继续占用配额直到清理结束。

## 限制访问与恢复

平台不设置功能总开关。需要收紧调用范围时调整允许服务/工具名单（`[]` 禁止全部业务工具），或撤销对应 Key；变更安全配置会取消进行中的编排，已产生副作用不撤销。原服务、Catalog `search_tools/call_tool`、Skills 与 ZIP/CLI 不因此改动。程序回退前停止实例接入和写入，不能再依赖旧 `enabled=false` 停止服务。

变更前保存完整配置和数据库/制品快照；回退程序时按 [匹配快照恢复流程](../maintainer/upgrade-recovery-drill.md)，不要只降低依赖版本。默认审计记录非秘密身份、来源、次数、耗时及错误，不记录完整代码、参数、结果或凭证。
